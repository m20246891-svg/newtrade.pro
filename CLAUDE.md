## ВАЖНЫЕ ПРАВИЛА

1. **CNAME файл нельзя трогать** — содержит `newtrade.pro`, без него сайт перестанет работать
2. **Все URL без .html** — страницы в папках с index.html (например `/products/indicators/`)
3. **Пути к assets** — всегда абсолютные от корня (`/assets/images/...`)
4. **Для вложенных страниц** (products/, blog/, legal/) — пути к CSS/JS через `../../assets/` или абсолютные
5. **После каждого изменения** — `git add . && git commit -m "..." && git push`
6. **Оплата** — не упоминать конкретный способ оплаты в юридических документах
7. **Финансовые советы** — сайт их не даёт, Максим продаёт ПО, не финансовые услуги
